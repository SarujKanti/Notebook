# Bundled fonts

The Font Style choices in Settings use these typefaces, all licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Sources: https://github.com/google/fonts (each family's folder has its OFL.txt).

| Style in the app | Typeface | Folder in google/fonts |
|---|---|---|
| Modern | Poppins | ofl/poppins |
| Clean | Lato | ofl/lato |
| Friendly | ABeeZee | ofl/abeezee |
| Classic | PT Serif | ofl/ptserif |
| Elegant | Crimson Text | ofl/crimsontext |
| Slab | Arvo | ofl/arvo |
| Typewriter | Courier Prime | ofl/courierprime |
| Handwritten | Indie Flower | ofl/indieflower |
| Script | Pacifico | ofl/pacifico |
| Display | Lobster | ofl/lobster |
